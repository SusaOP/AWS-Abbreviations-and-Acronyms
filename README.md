# AWS-Abbreviations-and-Acronyms
My personal, definitely not AWS-approved list of AWS Abbreviations and Acronyms for when I'm taking notes on AWS infrastructure, services, components, or really anything relating to writing about AWS tools. I've omitted the "AWS" and "Amazon" from the service names, as it felt too wordy. Feel free to use these as you see fit. It is not totally comprehensive of all AWS services. I will add new abbreviations and shorthand as necessary.

I've included some of Amazon's official abbreviated service names. For more official abbreviation conversations, look at the [AWS Glossary](https://docs.aws.amazon.com/glossary/latest/reference/glos-chap.html), the whitepaper [Continuous Integration and Continuous Delivery for 5G Networks on AWS](https://docs.aws.amazon.com/whitepapers/latest/cicd_for_5g_networks_on_aws/acronyms.html), and [AWS Service Names](https://aws.amazon.com/certification/policies/general-information/). 

Besides AWS, I've also included abbreviations for other words/phrases that I've seen come up often in my AWS studies, as well as across Technology, Security, Systems, Infrastructure Design, Objectives, etc.

I don't see a reason to make this any longer than a README file.
